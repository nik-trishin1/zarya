# NMT hypothesis artifacts

Dated Next Move Theory runs for **zarya** (market research, diagnosis, value propositions, interview extracts, strategy PRDs, GTM drafts).

These files are **hypotheses**, not product decisions. LLM estimates need a verification path (RAT) before they become a spec, ADR, or ticket.

Do not implement from a file in this folder in the same session. Handoff: field test → Human summary spec → ADR if the change leaves current MVP scope → Definition of Ready.

See `process/next-move-theory/README.md`.
